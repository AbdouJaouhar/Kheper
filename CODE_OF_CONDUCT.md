# Code of Conduct

Kheper welcomes constructive, respectful collaboration. Treat contributors, reviewers, learners, and subject specialists with care, especially when discussing cultural heritage, scholarly uncertainty, or accessibility needs.

Unacceptable behavior includes harassment, discrimination, personal attacks, intimidation, deliberate misinformation, and publishing private information without permission.

For a conduct concern, contact the repository maintainer privately through the GitHub profile associated with this repository. Do not open a public issue containing sensitive personal information.

The maintainer may remove, edit, or reject contributions and take any action needed to protect participants and the project.
