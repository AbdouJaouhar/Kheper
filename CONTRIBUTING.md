# Contribution status

Kheper is not accepting external contributions at this time. Please do not submit pull requests, patches, course content, documentation, assets, or translations.

The repository is publicly available so its product decisions, source code, and educational materials can be inspected. This does not currently imply that external work will be reviewed, merged, or incorporated.

This policy does not apply to private security disclosures. See [SECURITY.md](SECURITY.md) for the reporting process.

The maintainer will update this file when contribution intake opens.

## Maintainer workflow

Maintainer-authored changes follow the selected `KHEPER-xxx` ticket, branch,
review, merge, and validation rules in `AGENTS.md` and `MVP_BACKLOG.md`. Commits
must follow the certification and signature policy in
[docs/commit-policy.md](docs/commit-policy.md).

GitHub issue forms are present for maintainers to keep repository work
structured. Their presence does not open external contribution intake. Private
security reports continue to use [SECURITY.md](SECURITY.md).
